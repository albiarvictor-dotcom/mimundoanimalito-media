"Mi Mundo Animalito" is a personal, non-commercial content-production project. This page covers the small backend automation tool used internally to publish short animated video clips (produced for the "Mi Mundo Animalito" YouTube channel) to social platforms, including TikTok, using each platform's official developer APIs.

What this tool does

The tool is operated solely by its owner, for a single set of accounts that the owner controls. It authenticates with TikTok via OAuth and uses the Content Posting API to publish first-party video content — short animal-themed animated clips — that the owner has already produced and published on YouTube. It is not offered as a service to the public and does not accept sign-ups from other users.

Acceptable use

Because this is not a multi-user product, there is no public account registration or usage by third parties. Access to the connected TikTok account is limited to its owner.
